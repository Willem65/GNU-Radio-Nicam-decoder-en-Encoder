# Projecten Overzicht

Welkom. In deze hoofdmap vind je de bronbestanden en documentatie van de verschillende deelprojecten.

## Inhoud van de map

Alle projecten zijn zowel aanwezig als gecomprimeerd `.zip`-archief als in een reeds uitgepakte map:

* **[Mapnaam / Project 1]**: Korte omschrijving van project 1 (bijv. NICAM 728 Decoder flowgraph)
* **[Mapnaam / Project 2]**: Korte omschrijving van project 2 (bijv. NICAM 728 Transmitter flowgraph)
* **[Mapnaam / Project 3]**: Korte omschrijving van project 3 (bijv. BPSK-TX-RX)

---

## Handleiding voor gebruik

1. **Open een projectmap**: Navigeer naar een van de uitgepakte mappen (of pak het bijbehorende `.zip`-bestand uit als je op een nieuw systeem werkt).
2. **Bekijk de projectdocumentatie**: In elke afzonderlijke projectmap vind je een eigen `README.md`-bestand.
3. **Volg de instructies**: In die specifieke handleidingen staat precies beschreven:
   * Welke software, libraries en hardware nodig zijn.
   * Hoe je het project opstart en instelt.
   * Hoe de eventuele bediening werkt.

---

*Opmerking: Voor direct gebruik kun je de `.zip`-bestanden negeren en meteen in de reeds uitgepakte mappen aan de slag.*
